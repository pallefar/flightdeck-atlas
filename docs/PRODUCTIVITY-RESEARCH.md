# Productivity patterns for Atlas

Reviewed official product documentation on 17 September 2026. This is a selected feature roadmap, not a claim of feature parity or an objective ranking.

| Reference | Useful pattern | Atlas implementation |
| --- | --- | --- |
| [Todoist features](https://www.todoist.com/features) | Quick capture, Today/Upcoming, priorities, descriptions and subtasks, list/board/calendar views | Quick capture into an accessible Atlas project, separate planned/due dates, Today queue, seven-day deadlines, priorities, descriptions and checklists, project/task boards |
| [Linear triage](https://linear.app/docs/triage) and [workflow concepts](https://linear.app/docs/conceptual-model) | Deliberate prioritization, ownership and work states; review work before admitting it to a plan | Owner fields, To do/Doing/Blocked/Done, focused task filters, explicit Plan today, command menu |
| [Motion task manager](https://www.usemotion.com/features/ai-task-manager) | Separate work dates from deadlines, effort-aware planning, bottleneck warnings | Planned dates, task estimates, focus budget and blocked-work watch-outs. Calendar auto-scheduling is not implemented. |
| [Asana AI project management](https://asana.com/product/ai/project-management) | Goal-linked work, summarized status and identified blockers/next steps | Manual goals/KPIs, recorded updates, daily/weekly briefings and rule-based advisor. Model reviews await FlightDeck AI. |
| [Notion meeting notes](https://www.notion.com/product/ai-meeting-notes) | Keep decisions and action items beside their project context | Project updates and detailed tasks exist. Meeting capture/transcription awaits approved calendar/meeting integration; no recording is active. |

Next connection-dependent additions: FlightDeck strategy/KPI feeds, TEOA scorecards and AI review; Outlook email/calendar summaries; reviewed AI task breakdowns and priority suggestions. See STRATEGY-AI-CONTRACT.md and PERSONAL-HUB-CONTRACT.md.

Further product candidates after these workflows are validated: recurring task templates, dependencies/critical paths, saved custom views, attachments and an approval inbox. These are roadmap items, not working controls.
